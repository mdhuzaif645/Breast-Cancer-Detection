# 🎀 Breast Cancer Prediction Studio

An interactive machine learning application that predicts whether a breast tumour is more likely to be **malignant or benign** using Logistic Regression. Built with Python and Gradio, the application provides interactive visualizations to help users understand the model's predictions.

## 🚀 Features

- **Tumour Prediction:** Analyze five measurements to generate a model prediction.
- **Interactive Visualizations:** View a schematic breast anatomy diagram and a magnified cell nucleus illustration.
- **Risk Gauge:** Explore the model's estimated probability of malignancy.
- **Feature Contributions:** Understand how individual measurements influence the prediction.
- **What-if Analysis:** Explore how changing one measurement affects the model output.
- **Decision Map:** Visualize the model's decision boundary using two selected features.
- **Model Insights:** View learned weights and learn about the model's limitations.
- **Quick Examples:** Try typical malignant, benign, and median measurement presets.

## 🧠 Machine Learning Model

The application uses Logistic Regression with a feature scaler.

The model analyzes these five features:

1. Mean radius
2. Mean texture
3. Mean perimeter
4. Mean area
5. Mean smoothness

The measurements are scaled before being passed to the trained model. The application then calculates the estimated probability of malignancy and displays a prediction according to the selected decision threshold.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd YOUR_REPOSITORY_NAME
```

Replace the URL and repository name with your actual GitHub repository details.

### 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

Open the local URL displayed in your terminal, usually `http://127.0.0.1:7860`.

## 📊 How to Use

1. Open the **Diagnose** tab.
2. Adjust the five tumour measurement sliders or select a quick example.
3. Choose a decision threshold.
4. Click **Analyze**.
5. Explore the prediction, risk gauge, feature contributions, and what-if charts.
6. Open the **Decision map** tab to explore the model's decision boundary.
7. Open **How it works** to understand the model and its limitations.

## ⚠️ Disclaimer

This project is intended **for educational and demonstration purposes only**. It is not a medical device and must not be used to diagnose breast cancer or make treatment decisions.

The predictions are generated by a machine learning model trained on a limited set of features. They are not a substitute for professional medical evaluation, diagnostic imaging, biopsy, or advice from a qualified healthcare professional.
